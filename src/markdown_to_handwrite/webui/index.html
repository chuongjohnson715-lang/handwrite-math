常见问题

设定书写区域

在背景上拖拽画出正文可以书写的部分；框内序号即填写顺序。

拖拽空白处新建区域；拖动框体移动，拖动右下角调整大小。

摆正背景

按顺序点纸张的四个角：左上、右上、右下、左下。程序把纸拉成正矩形，横线随之变水平。

已点 0 / 4 个角

手动标定横线

对两条相邻的横线各点左右两端：上线左端 → 上线右端 → 下线左端 → 下线右端。程序按这两条线的间距和倾斜铺满整页，照片拍斜、横线在图上不水平也能压准。

已点 0 / 4 个点：点第一条横线的左端

分节背景

给不同的节指定不同底图；选了底图的节会另起一页，没选的节沿用上面的全局背景。
